# HabitPulse — Daily Routine & Energy Tracker

> A modern, ultra-slick daily habit routine, recurring calendar, and energy correlation engine crafted with a Linear/Vercel-inspired glassmorphism aesthetic.

Designed and engineered with precision by **AnshuMan**.

---

## ✨ Features

- **Daily Habit Tracking**: Check off daily routines with smooth motion animations and automatic streak calculation.
- **100% Day Completion Celebration**: Lightweight dual-cannon canvas confetti effect when finishing all remaining daily habits.
- **Energy & Mood Correlation Engine**: Log 1–5 daily energy scores and mood tags; statistical cross-analysis highlights your highest vitality catalysts.
- **Interactive Calendar with Cycle Repetition**: Schedule events repeating daily, weekly, monthly, or yearly with checkoffs.
- **Audio Alarm Chimes & Notifications**: Native Web Audio API chime synthesizer for reminders, lead times (5m, 15m, 30m, 1h), and desktop notification support.
- **Streak Freeze Shield**: 1 emergency freeze shield per week to preserve streaks when life gets busy.
- **Dynamic Time Greetings**: Morning, afternoon, evening, and night personalized greetings with user profile goals.
- **Birthday Wishing Mode**: Annual milestone alerts with musical fanfare and celebration bonus.
- **Data Portability**: Full offline LocalStorage persistence with one-click JSON backup export and import.
- **Dark & Light Mode**: Obsidian dark mode (default) and clean light mode.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 + Glassmorphism
- **Animations**: Motion (Framer Motion) + Canvas Confetti
- **Analytics**: Chart.js
- **Icons**: Lucide React
- **Audio**: Web Audio API (zero external sound dependencies)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/habitpulse.git
cd habitpulse
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 4. Build for production
```bash
npm run build
```
